# Audiobook Player — Android

An offline audiobook player. Pick any folder (internal storage or SD card), and it remembers where you stopped in every book.

**Download:** https://github.com/YOUR-USERNAME/audiobook-player-releases/releases/latest/download/Audiobook-Player.apk
(All versions: the *Releases* page of this repository.)

## Install
1. Open the link above on your Android phone and download the file.
2. Open the downloaded `Audiobook-Player.apk`.
3. If Android asks, allow installing apps from your browser or Files app, then tap **Install**.
4. If Play Protect shows a warning, tap **More details → Install anyway** (the app is not distributed through Google Play).

New versions install over the old one and keep your progress, bookmarks and settings.

## Features
- Any folder or SD card, nested folders, search, grid or list view
- Progress for every file and book, smart playlists (in progress, completed, new, recent), history and listening stats
- Notification and lock-screen controls with a seek bar; chapters; sleep timer; speed per book; repeat modes; up-next queue
- Cover art from the files (or `cover.jpg`), Arabic and English with right-to-left layout, light and dark themes
- Automatic backup of your progress to a folder you choose

## Privacy
The app has no accounts, no ads and no analytics. Your files, progress and settings stay on your phone (and in the backup folder if you choose one).
The "internet" permission is only used for a private audio server inside the phone that lets the player read your files and seek.

## Permissions
- **Notifications / foreground service** — playback controls in the notification bar
- **Folder access** — only the folders you pick in the Android folder picker
